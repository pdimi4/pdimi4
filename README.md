## Featured Project

### Charlotte Neighborhood Housing Price Analysis

A machine learning project analyzing how economic, educational, housing, and public-safety factors relate to neighborhood housing prices in Charlotte, North Carolina.

The project combines multiple neighborhood-level datasets using Python, pandas, and SQLite and applies regression and classification models to housing-price prediction.

**Methods used:**
- Data cleaning and preprocessing
- SQL-based data integration
- Linear Regression
- K-Nearest Neighbors
- Random Forest
- Cross-validation
- Hyperparameter tuning
- RMSE and R² evaluation
- Accuracy and ROC-AUC evaluation
- Feature importance analysis
